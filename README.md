# Digital Clock

## Overview

A simple and responsive digital clock built using HTML, CSS, and JavaScript. The application displays the current time and updates every second in real time.

## Features

- Real-time clock
- Updates every second
- Responsive user interface
- Lightweight design
- Beginner-friendly project

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How to Run

1. Clone this repository.
2. Open the project folder.
3. Open `project1.html` in your web browser.
